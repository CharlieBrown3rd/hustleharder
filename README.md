# HUSTLE HRDR

Master project repository for the HUSTLE HRDR brand.

## Brand Architecture

HUSTLE HRDR is the master brand.

Core recurring marks:
- HUSTLE HRDR
- HSTL HRDR
- HRDR

The master identity remains consistent while individual collections are allowed to develop their own typography, graphics, mood, and visual language.

## Current Collections

### AFTER HOURS
Minimal, editorial, understated, nocturnal.

### NEXT SERIES
Sharper, industrial, angular, technical, high-impact.

## Project Structure

- `brand/` — master identity system
- `collections/` — collection-specific creative work
- `products/` — product development
- `content/` — campaigns, photography, copy, social
- `docs/` — strategy and project decisions
- `assets/` — shared production assets
- `web/` — future HUSTLE HRDR website
